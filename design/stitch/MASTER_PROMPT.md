# NetMind — Soft Liquid Minimal

Create a desktop-first network operations interface for **NetMind AI** using a **teal-first Soft Liquid Minimal** system. The experience is quiet, clinical, and highly legible for network operators—not a neon cyber dashboard.

- Dark-first canvas `#10141C`; provide a high-contrast light alternate with canvas `#F7F8FC`.
- Use Operational Teal `#0D9E96` as the primary action/focus color; hover `#14B8A6`; teal wash `#103536`.
- Use opaque panels for charts, topology graphs, and telemetry. Limit translucent `backdrop-filter: blur(8px)` surfaces to top bars, floating filters, and dialogs.
- Use Inter for interface copy and JetBrains Mono with tabular numerals for IPs, throughput, latency, and logs.
- Follow an 8px rhythm, 12-column desktop grid, crisp 1px borders, 8px controls, and 12–16px panels. Keep motion to 120–180ms ease-out.
- Operational states: healthy emerald, routing blue, warning amber, critical crimson. Reserve pill shapes for compact state badges.
- Include a dark and light token preview. Avoid gradients, glow effects, heavy shadows, and decorative density.
